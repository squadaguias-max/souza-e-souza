# Template 3 — Advocacia Clássica

Landing page jurídica com direção visual clássica, luminosa e editorial. A composição utiliza hero arquitetônico escuro, formulário de agendamento em destaque, tons de marfim e dourado, áreas de atuação, diferenciais, FAQ, contato e localização.

## Personalização

Edite `src/config/template.config.js` para alterar marca, WhatsApp, telefone, e-mail, endereço, horários e localização do mapa.

Os textos, áreas de atuação, benefícios e perguntas frequentes ficam em `src/modules/home/pages/HomePage.jsx`.

## Executar

```bash
npm install
npm run dev
```

Verificação:

```bash
npm run lint
npm run build
```

## Antes de publicar

- substitua os dados demonstrativos;
- troque as imagens pelas fotografias autorizadas do cliente;
- confirme WhatsApp, endereço e rota;
- revise OAB, credenciais e áreas de atuação;
- não publique promessas de resultado;
- teste a página em celular, tablet e computador.
